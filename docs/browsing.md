# Browsing

One change to the browse screen: you can drag a track to a new position in a
playlist, and your stick keeps the new order.

## The EDIT toggle

On the browse screen, dragging with one finger scrolls the list. To reorder tracks instead, use the **EDIT** toggle in the browse header. It lights up while on. When EDIT is on, dragging moves a track; when it is off, dragging scrolls the list as usual.

## Reordering a playlist

1. Open a **playlist** (with the **BROWSE** or **PLAYLIST** button).
2. Tap **EDIT** in the browse header.
3. **Drag a track** to where you want it.
4. Tap **EDIT** again when you are done.

![EDIT on and a track mid-drag, on its way to a new position.](img/browse-edit-on.png)

## Playlists only

In a playlist, `#` is the track's stored position in that list, so moving a
track changes the list. In an album or artist view, `#` is the track number
from its tags, so there is no order to change. EDIT therefore appears only on
playlist views.
