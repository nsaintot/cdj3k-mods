# MOD SETTINGS

Where you switch the mods' features on and off. It opens over the UTILITY
screen, with its own categories on the left, like the deck's own settings.

## Opening it

1. Press **MENU/UTILITY**.
2. Look at the **top right** of the screen, where the deck shows its firmware
   version.
3. **Tap the version label.**

![The UTILITY screen. The version at the top right reads Ver.3.22-m, and the -m shows the mods are loaded.](img/mod-settings-ver-label.png)

The version ends in **`-m`** and is drawn brighter whenever the mods are
installed. This is the only sign on the stock screen that they loaded.

![MOD SETTINGS open over UTILITY: the title reads MOD SETTINGS, the categories are on the left, GATE CUE is selected and the right pane offers OFF and ON.](img/mod-settings-open.png)

The version label turns **blue** while MOD SETTINGS is showing. Tap it again,
press **BACK** from the category column, or leave the screen to return to the
deck's own settings.

It works like the deck's own settings: turn the rotary to move, push it to go
one column right, press **BACK** to go one column left. Touch works too.

## Settings

| Category | Row | Options | Ships as |
| --- | --- | --- | --- |
| PLAYER SETTING | **GATE CUE** | OFF / ON | OFF |
| | **SMART CUE** | OFF / ON | OFF |
| | **PREVIEW HOTCUE** | OFF / ON | OFF |
| | **ENABLE X-PAD** | OFF / ON | OFF |
| STEMS | **ENABLE STEMS** | OFF / ON | OFF |
| | STEM MUTE MODE | HOLD / TOGGLE | HOLD |
| | STEM MUTE PADS | OFF / ON | OFF |
| | STEM SERVER LOCATION | AUTO / MANUAL | AUTO |
| | STEM SERVER ADDRESS | text | empty |
| DISPLAY | **THEME** | theme list | ORIGINAL |
| ABOUT | VERSION, BUILD | read-only: which mods you are running | – |

> **Note:** All features are off by default.

After installing, the deck behaves as stock until you turn features on.

![The STEMS category with ENABLE STEMS switched on, so STEM SERVER LOCATION has appeared beneath it.](img/mod-settings-stems.png)

## Where your settings are kept

Settings are saved in the deck's internal storage.
